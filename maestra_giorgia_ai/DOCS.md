# Maestra Giorgia AI

Dopo l'installazione apri l'app dalla barra laterale di Home Assistant.

## Gemini
Apri **Impostazioni** dentro Maestra Giorgia AI, incolla la Gemini API key e premi **Salva** / **Test AI**.

## Privacy
Con Gemini, prompt e immagini vengono inviati al servizio Google. Per dati scolastici reali usa il minimo di dati identificativi necessario.

## Dati
I dati dell'app sono salvati nel volume persistente `/data`.
