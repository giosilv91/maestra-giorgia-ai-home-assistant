# Maestra Giorgia AI

App Home Assistant del progetto **GM Maestra AI**, per Giorgia Mauro e il sostegno nella scuola primaria.

Funzioni principali:
- assistente Maestra;
- profili alunni;
- valutazioni;
- obiettivi;
- diario didattico;
- generazione di schede e verifiche;
- Gemini;
- Occhi AI;
- dati persistenti nel volume dell'app.
